# EcoLeón
- ## ¿Qué es #EcoLeon ?
EcoLeon es un proyecto prototipo universitario que nos permitirá desarrollar nuestras habilidades dentro de HTML, CSS y JavaScript y realizar creaciones propias en beneficio profesional o extracurricular.

El proyecto consiste un sistema semi-autonomo que le permita a las personas de León, Guanajuato el poder monitorear su consumo de agua y como hacer un mejor manejo de ella.

![ImagenPrueba1](/readmeImg/test1.png)
- ## ¿Cómo planeamos hacerlo?
Se plenea la solicitud de al Sitema de Agua Potable y Alcantarillado de León la vinculación a la base de datos por medio del programa de SAPAL llamado "[Desarrolladores](https://developers.sap.com/api-docs/)".

> **Advertencia:** Este es un proyecto prototipo sin fines de lucro; es proable que no cuente con un sistema estable al 100% al ser unicamente un proyecto universitario por parte de la *Universidad Tecnologica de León*.
